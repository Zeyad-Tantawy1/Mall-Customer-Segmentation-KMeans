# 🛍️ Customer Segmentation with K-Means

##  Overview
This project applies **K-Means clustering** to segment customers based on their purchase history. The goal is to uncover patterns that can support personalized marketing strategies.

##  Steps
- Preprocessed customer transaction data.
- Applied **K-Means clustering** for segmentation.
- Visualized clusters to interpret customer groups.

## 📊 Results
- Identified distinct customer segments.
- Discovered behavioral patterns useful for targeted campaigns.

##  Next Steps
- Experiment with other clustering algorithms (DBSCAN, Hierarchical).
- Integrate domain knowledge to validate and refine clusters.
